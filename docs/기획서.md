# deep dive 게임 기획서

	- 게임: deep dive
	- 작성자: 김창섭

## 개요

	- 장르: 아케이드
	- 게임 소개
		- 플레이어는 잠수부를 조작하여 장애물을 회피하고 최대한 깊은 수심까지 내려가는 게임
		- 소지품의 무게에 따라 하강 속도가 변화
		- 주변 오브젝트를 획득하거나 소지품을 버려 하강 속도 조절
		- 방귀를 이용해 현재 플레이어 진행 방향을 향한 추진력을 얻을 수 있음, 플레이어가 정지 상태인 경우 방귀 발사 시 위로 상승
			- 재미 요소
			 - 오브젝트 획득과 처분을 통한 상황 대처	
			 - 무게에 따른 하강 속도 조절
			 - 장애물 회피를 위한 빠른 판단과 조작

## 게임 진행

	1. 플레이어는 수면에서 잠수를 시작한다.
	2. 일정 거리 내의 오브젝트를 마우스 좌클릭으로 획득한다.
	3. 소지품의 무게에 따라 하강 속도가 변화한다.
	4. 획득한 오브젝트의 무게가 총무게에 반영된다.
	5. 상황에 따라 소지품을 버리거나 새로운 오브젝트를 획득하여 속도를 조절한다.
	6. 좌우 이동과 방귀를 이용해 장애물을 회피한다.
	7. 수심이 깊어질수록 장애물의 배치와 난이도가 변화한다.
	8. 게임 종료 시 최대 도달 수심을 기록한다.



## 조작
- a : 왼쪽으로 이동
- b : 오른쪽으로 이동
- 스페이스바 : 위로 이동
- 마우스 좌클릭 : 원거리에 있는 아이템을 흡입기를 사용해 빨아드림
- 마우스 우클릭 : 아이템 버리기
- shift : 방귀 뀌기

## 게임 오브젝트
- 1스테이지 아이템 : 획득 시 무게 1 증가
- 2스테이지 아이템 : 획득 시 무게 3증가
- 3스테이지 아이템1,2,3,4 : 획득 시 무게 10증가
- 1스테이지 적 : 플레이어에게 공격 적중 시 2데미지를 주고 1초간 경식시킴
- 2스테이지 적 : 플레이어게 공격 적중 시 5의 데미지를 줌. 1스테이지 적보다 빠른 이동 속도
- 3스테이지 적1 : 플레이어에게 공격 적중 시 7의 데미지를 줌, 3스테이지 적1은 항상 무리지어 다님
- 3스테이지 적2 : 플레이어에게 공격 적중 시 15의 데미지를 줌, 다른 적들에 비해 넓은 시야를 가짐
- 장애물 1,2,3 : 플레이어의 현재 속도가 50이상인 경우 장애물에 닿을 시 플레이어에게 10의 데미지를 줌
 ## 게임 시스템
 - 플레이어 현재 속도 = 플레이어가 지닌 아이템 무게
 - 적 어그로는 플레이어가 적의 시야에서 사라지면 즉시 풀림


## 플레이 Stage

	- 수직으로 이어지는 무한 스크롤 스테이지
	- 수심이 깊어질수록 장애물 밀도 증가
	- hp가 0이 되면 게임 종료
