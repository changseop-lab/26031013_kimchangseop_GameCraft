# deep dive 게임 기획서

	- 게임: deep dive
	- 작성자: 김창섭

## 개요

	- 장르: 아케이드
	- 게임 소개
		- 플레이어는 잠수부를 조작하여 장애물을 회피하고 최대한 깊은 수심까지 내려가는 게임
		- 소지품의 무게에 따라 하강 속도가 변화
		- 주변 오브젝트를 획득하거나 소지품을 버려 하강 속도 조절
		- 방귀를 이용해 상승 추진력을 얻을 수 있음
			- 재미 요소
			 - 오브젝트 획득과 처분을 통한 상황 대처	
			 - 무게에 따른 하강 속도 조절
			 - 장애물 회피를 위한 빠른 판단과 조작

## 게임 진행

	1. 플레이어는 수면에서 잠수를 시작한다.
	2. 일정 거리 내의 오브젝트를 마우스 좌클릭으로 획득한다.
	3. 소지품의 무게에 따라 하강 속도가 변화한다.
	4. 획득한 오브젝트의 무게가 총무게에 반영된다.
	5. 상황에 따라 소지품을 버리거나 새로운 오브젝트를 획득하여 속도를 조절한다.
	6. 좌우 이동과 방귀를 이용해 장애물을 회피한다.
	7. 수심이 깊어질수록 장애물의 배치와 난이도가 변화한다.
	8. 게임 종료 시 최대 도달 수심을 기록한다.



## 조작
- a : 왼쪽으로 이동
- b : 오른쪽으로 이동
- 스페이스바 : 위로 이동
- 마우스 좌클릭 : 원거리에 있는 아이템을 장비를 사용해 빨아드림
- 마우스 우클릭 : 아이템 버리기


## 플레이 Stage

	- 수직으로 이어지는 무한 스크롤 스테이지
	- 수심이 깊어질수록 장애물 밀도 증가
	- 장애물 5회 충돌 시 게임 종료
